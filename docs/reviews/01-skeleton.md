# 里程碑审查 1：行走骨架（PR #1）

- 方式：多 agent 冷启动审查（无上下文并行找缺陷 → 逐条验证 → 按严重度排序），强度 medium
- 结果：10 项，均核实为真
- 处理原则：参数校验、边界类问题直接修复并补测试；涉及确认边界等设计取舍的问题由我决定修法与时机

| # | 问题 | 风险 | 处理 |
|---|---|---|---|
| 1 | 模型多传参数时 `**args` 抛 TypeError，整次运行崩溃、无报告 | 低（边界） | 已修：未知参数返回 INVALID_ARGS；工具内部异常转为 TOOL_ERROR 观察 |
| 2 | 参数是合法 JSON 但非对象（如 `null`）时崩溃 | 低（边界） | 已修：统一按非法参数返回 |
| 3 | 报告采信模型自报的 `needs_confirmation`，"擅自改时间"可能被报为已完成 | **高（确认边界）** | 切片 2：报告按 `suggested_slot ≠ requested_slot` 判定；`save_draft` 守卫在保存时拒绝 |
| 4 | 参数不校验类型，`"false"` 字符串被当真 | 低（边界） | 已修：按工具定义校验类型 |
| 5 | 素材先存草稿后被阻断，草稿与占位残留 | **中（数据一致性）** | 已修（切片 1，PR #2）：存储层就绪后提前处理，阻断时同事务撤销草稿、释放时段，报告显示 cancelled 与释放的时段 |
| 6 | 输入文件结构异常时打印堆栈 | 低（边界） | 已修 |
| 7 | `--max-tool-calls 0` 被忽略、负数被接受 | 低（边界） | 已修：正整数校验 |
| 8 | `.env` 引号 / `export` 前缀导致 key 错误 | 低（边界） | 已修 |
| 9 | 总结含"未发布"时跳过"已发布"检查 | 低（边界） | 已修 |
| 10 | 工具次数用尽后仍多发一次付费模型请求 | 低（成本） | 已修：每轮开始前检查 |
