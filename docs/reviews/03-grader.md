# 交付前审查：冷启动阅卷评审

- 方式：一个无上下文的 agent 以阅卷人立场，从公开仓库重新克隆提交版本，运行测试与离线 Mock、自行构造隐藏测试（更换占用时段重提、修改数据重跑、注入失败、上限等），按试卷五个维度评分；真实模型效果依据已提交的运行记录核对
- 结论：关键缺陷（越权发布、虚报保存成功）均未发现；离线 Mock 结果可逐行复现；发现 1 个跨运行边界问题，已修复

| 发现 | 处理 |
|---|---|
| 上一轮保存的草稿被当作本轮结论：素材数据变为违规后，本轮未复审即结束仍会报"已完成" | `finish` 只认本轮成功的动作，库中旧草稿须本轮复审（重新保存会再过守卫，含本轮规则检查）；报告中未复审的旧草稿如实标为未处理，草稿事实照常展示。回归测试 `tests/test_grader_fixes.py` |

评审提到的其余改进方向已列入 [03-evaluation §5](../03-evaluation.md#5-已知限制) 与 [05-retrospective](../05-retrospective.md) 的下一步。
